# TOJI PROTOCOL — fontes das fotos

O banco usa fotos reais de exercícios. As imagens mapeadas via Free Exercise DB seguem os caminhos públicos do repositório yuhonas/free-exercise-db. O próprio repositório descreve o dataset como público e permite acesso local/hosted, mas há discussões sobre a licença das imagens; por isso elas estão marcadas como `real_photo_source`, não como licença individualmente verificada.

As fotos selecionadas do Wikimedia Commons ficam marcadas como `verified_real_photo` quando a página da fonte permitiu conferir a licença/atribuição.

Nenhuma ilustração, boneco ou imagem gerada é usada como substituta.
