# TOJI PROTOCOL — fontes de fotos

Esta versão **não usa bonecos/ilustrações como substitutos**.

As fotos reais verificadas estão vinculadas por exercício em `db.json`. Quando uma fonte fotográfica real adequada ainda não foi encontrada, `photo_url` fica `null` e a interface informa isso explicitamente.

As fotos desta fundação vêm de **Wikimedia Commons**, com crédito/licença registrados no banco. Exemplos incluem fotos reais de lat pulldown, seated row, chest press, bench press, shoulder press, pec deck, leg press, leg extension, pull-up, plank, cable crossover e dips.

O banco de exercícios foi separado da interface para permitir que as 48 fotos sejam revisadas/substituídas sem alterar a estrutura do app.
